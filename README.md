# Парсер Вакансий для Rabota.md

Проект для парсинга вакансий с сайта rabota.md и других job-порталов.

## ✨ Возможности

- 🔍 Поиск профессии по названию на rabota.md
- 📋 Извлечение списка вакансий с первой страницы
- 💼 Сбор информации: название, компания, зарплата, локация, ссылка
- 🎯 Правильная типизация с TypeScript
- 🧪 Тесты с Vitest

## 🚀 Быстрый старт

## 🎯 Как это работает

1. **Поиск профессии**: Парсер открывает страницу поиска и ищет ссылку на нужную профессию
2. **Переход на страницу профессии**: Переходит по найденной ссылке
3. **Извлечение вакансий**: Парсит карточки вакансий (`.vacancyCardItem`)
4. **Сбор данных**: Извлекает название, компанию, зарплату, локацию
5. **Возврат результата**: Возвращает массив вакансий с правильной типизацией

## 📝 Использование

```typescript
import { RabotaMdParser } from './parsers/rabotaMd.js';

const parser = new RabotaMdParser();

const result = await parser.parse({
  baseUrl: 'https://www.rabota.md',
  searchQuery: 'программист',
});

console.log(`Найдено: ${result.vacancies.length} вакансий`);

result.vacancies.forEach(vacancy => {
  console.log(`${vacancy.title} - ${vacancy.company}`);
});
```

## 🔧 Конфигурация

Измените параметры в `src/main.ts`:

```typescript
const config: ParserConfig = {
  baseUrl: 'https://www.rabota.md',
  searchQuery: 'программист',  // ← Измените профессию
  maxPages: 1,
  delay: 1000,
};
```
