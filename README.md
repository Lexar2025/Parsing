# Парсер Вакансий - Молдова

Многофункциональный парсер вакансий с поддержкой популярных сайтов Молдовы.

## 🎯 Поддерживаемые сайты

- ✅ **rabota.md** - работает через обычный HTTP парсинг
- 🔧 **999.md** - требует Puppeteer (Next.js + динамическая загрузка)

## 📦 Установка

```bash
npm install
```

### Для парсинга 999.md установите Puppeteer:

```bash
npm install puppeteer
```

## 🚀 Использование

### Парсинг rabota.md (готово к использованию)

```bash
npm run build
npm run start
```

Или универсальная команда:
```bash
npm run parse rabota.md программист
```

### Парсинг 999.md (требует Puppeteer)

```bash
npm run start:999
```

Или:
```bash
npm run parse 999.md Грузчик
```

## ⚙️ Конфигурация

Настройки находятся в `src/config/parsers.ts`:

```typescript
export const PARSER_CONFIGS: Record<string, SiteConfig> = {
  'rabota.md': {
    name: 'Rabota.md',
    baseUrl: 'https://www.rabota.md',
    defaultCategory: 'программист',
    maxPages: 10,
    delay: 1000,
    concurrency: 3,
    cacheEnabled: true,
  },
  '999.md': {
    name: '999.md',
    baseUrl: 'https://999.md',
    defaultCategory: 'Грузчик',
    maxPages: 10,
    delay: 1500,
    concurrency: 3,
    cacheEnabled: true,
  },
};
```

**Параметры:**
- `maxPages` - максимальное количество страниц для парсинга
- `delay` - задержка между запросами (мс)
- `concurrency` - количество одновременных запросов
- `cacheEnabled` - включить/выключить кэширование
- `defaultCategory` - категория по умолчанию

## 🐛 Проблема с 999.md

**Почему 999.md не работает с обычным HTTP?**

999.md использует **Next.js** и загружает контент динамически через JavaScript. Простой HTTP запрос (axios) не видит карточки вакансий, так как они появляются только после выполнения JS.

**Решение:** Использовать **Puppeteer** - headless браузер, который выполняет JavaScript.

### Установка Puppeteer

```bash
npm install puppeteer
```

После установки парсер 999.md будет переписан для работы через Puppeteer.

## 📊 Кэширование

Парсеры используют файловый кэш для детальной информации:

```
cache/
├── rabota-md/      # Кэш для rabota.md

```

**Время жизни кэша:** 24 часа

Кэш автоматически обновляется при устаревании данных.

## ⚠️ Troubleshooting

### HTTP 429 - Too Many Requests
Увеличьте `delay` в конфигурации сайта (например, до 2000-3000 мс).

### Пустые результаты на 999.md
1. Убедитесь, что установлен Puppeteer
2. Проверьте точное название категории на сайте
3. Попробуйте другую категорию

### Категория не найдена
Проверьте точное написание категории на сайте 999.md в разделе "Работа".

## 🤝 Вклад

Если хотите добавить поддержку нового сайта:

1. Создайте файл в `src/parsers/yourSite.ts`
2. Реализуйте интерфейс `Parser` из `src/types/vacancy.ts`
3. Добавьте конфигурацию в `src/config/parsers.ts`
4. Добавьте парсер в switch в `src/parse.ts`
