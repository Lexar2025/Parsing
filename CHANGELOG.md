## Что было сделано

### 1. Создан новый парсер для 999.md
**Файл:** `src/parsers/nineNineNineMd.ts`

Основные возможности:

- Кэширование результатов

### 2. Обновлены типы данных
**Файл:** `src/types/vacancy.ts`

Добавлен новый источник:
```typescript
source: 'rabota.md' | '999.md' | 'other';
```

### 3. Создан конфигурационный файл
**Файл:** `src/config/parsers.ts`

Централизованная конфигурация для всех парсеров:
- Параметры сайта (URL, категории по умолчанию)
- Настройки парсинга (количество страниц, задержки)
- Опции кэширования

### 4. Создан универсальный парсер
**Файл:** `src/parse.ts`

Позволяет запускать любой парсер через единую команду:
```bash
npm run parse <сайт> [категория]
```

Функции:
- Автоматический выбор парсера по названию сайта
- Вывод статистики по категориям
- Сохранение результатов в отдельные файлы
- Справка по доступным парсерам

### 5. Обновлен package.json
Добавлены новые скрипты:
- `npm run start:999` - запуск парсера 999.md
- `npm run parse` - универсальный парсер

### 6. Создана документация
- **PARSER_README.md** - полная документация по проекту
- **TEST_999MD.md** - инструкция по тестированию 999.md
- **CHANGELOG.md** (этот файл) - описание изменений

## Технические детали

### Обработка пагинации на 999.md
999.md использует параметр `?page=N` для пагинации:
- Страница 1: `?appl=1`
- Страница 2: `?appl=1&page=2`
- Страница 3: `?appl=1&page=3`

### Структура HTML 999.md
- Список вакансий: `.styles_adlist__3YsgA`
- Карточка вакансии: `article.AdVacancies_wrapper__oZp_b`
- Заголовок: `h5.AdVacancies_title__link__V9IOY a`
- Характеристики: `.AdVacancies_features__item__IBTIr`

### Фильтр "Предлагая работу"
Параметр `appl=1` в URL означает "предлагаю работу" (employer mode).
Без этого фильтра будут показываться резюме (ищу работу).
