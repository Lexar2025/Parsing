# Чеклист тестирования парсера 999.md

## Перед запуском

- [ ] Node.js установлен (версия 22+)
- [ ] Зависимости установлены (`npm install`)
- [ ] Проект собран (`npm run build`)

## Базовое тестирование

### 1. Тест с категорией "Загрузчик"
```bash
npm run parse 999.md Загрузчик
```

**Ожидаемый результат:**
- [ ] Парсер успешно запускается
- [ ] Находит категорию "Загрузчик"
- [ ] Добавляет фильтр appl=1
- [ ] Парсит хотя бы 1 страницу
- [ ] Извлекает вакансии (проверьте количество)
- [ ] Сохраняет результат в `vacancies_999_md.json`

**Что проверить в логах:**
```
✅ Найдена ссылка на категорию: https://999.md/ru/list/work/...
✅ URL с фильтром: https://999.md/ru/list/work/...?appl=1
✅ Найдено X вакансий (всего: X)
```

### 2. Проверка JSON файла
```bash
cat vacancies_999_md.json | head -n 50
```

**Проверьте структуру:**
- [ ] Массив объектов
- [ ] У каждой вакансии есть поля:
  - [ ] `id`
  - [ ] `title`
  - [ ] `url`
  - [ ] `source` = "999.md"
  - [ ] `schedule` (если есть)
  - [ ] `experience` (если есть)
  - [ ] `education` (если есть)

### 3. Тест с другой категорией
```bash
npm run parse 999.md Водитель
```

**Ожидаемый результат:**
- [ ] Успешный парсинг
- [ ] Результаты отличаются от предыдущего теста
- [ ] Вакансии соответствуют категории

## Тестирование пагинации

### 4. Проверка нескольких страниц
В `src/config/parsers.ts` измените `maxPages` на 3:
```typescript
'999.md': {
  maxPages: 3,  // ← измените здесь
  ...
}
```

Пересоберите и запустите:
```bash
npm run build
npm run parse 999.md Загрузчик
```

**Проверьте в логах:**
- [ ] Парсятся страницы 1, 2, 3
- [ ] URL каждой страницы корректен
- [ ] Общее количество вакансий растет
- [ ] Нет дублей (проверьте id)

## Тестирование ошибок

### 5. Несуществующая категория
```bash
npm run parse 999.md "НесуществующаяКатегория123"
```

**Ожидаемый результат:**
- [ ] Сообщение "Категория ... не найдена"
- [ ] Парсер завершается корректно
- [ ] JSON файл пустой или содержит []

### 6. Проверка задержек
В `src/config/parsers.ts` уменьшите delay до 500:
```typescript
'999.md': {
  delay: 500,  // ← уменьшите
  ...
}
```

**Возможный результат:**
- [ ] Либо работает нормально
- [ ] Либо получаете ошибку 429 (Too Many Requests)

Если получили 429, верните delay обратно к 1500.
