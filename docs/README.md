# 🔍 Парсер Вакансий - Молдова

Многофункциональный парсер вакансий с отслеживанием актуальности для популярных сайтов Молдовы.

## 📊 Текущее состояние проекта

### ✅ Реализовано

#### Парсеры:
- **✅ rabota.md** - HTTP парсинг через axios + JSDOM
  - Поиск по профессиям
  - Пагинация с проверкой дубликатов ID
  - Детальный парсинг вакансий
  - Кэширование результатов
  
- **✅ 999.md** - Puppeteer (headless browser)
  - Поддержка Next.js динамического контента
  - Правильные фильтры (appl=1, ef, o_16_1)
  - Определение реального количества страниц
  - Детальный парсинг с извлечением всех полей
  - Кэширование

#### Система управления актуальностью:
- **✅ VacancyManager** - отслеживание жизненного цикла вакансий
  - `firstSeenAt` - когда вакансия впервые найдена
  - `lastSeenAt` - когда найдена в последний раз
  - `isActive` - активна ли сейчас
  - Автоматическое обновление статусов
  - Удаление неактивных старше N дней

#### Утилиты:
- **✅ Кэширование** - файловый кэш с TTL (24 часа)
- **✅ Управление вакансиями** - CLI утилита для просмотра и очистки
- **✅ Статистика** - детальная аналитика по вакансиям
- **✅ Проверка дубликатов** - умное определение конца пагинации

## 💾 Формат данных

### Структура вакансии

```typescript
interface Vacancy {
  // Основные поля
  id: string;
  title: string;
  company?: string;
  salary?: string;
  location?: string;
  description?: string;
  url: string;
  
  // Детали работы
  education?: string;
  experience?: string;
  schedule?: string;
  workPlace?: string;
  
  // Для 999.md
  author?: string;           // Физ./Юр. лицо
  seasonal?: boolean;        // Сезонная работа
  employmentType?: string;   // Тип занятости
  companyType?: string;      // Тип компании
  languages?: string[];      // Требуемые языки
  contactPerson?: string;    // Контактное лицо
  region?: string;           // Регион/адрес
  
  // Отслеживание актуальности
  firstSeenAt?: Date;        // Когда впервые найдена
  lastSeenAt?: Date;         // Когда найдена последний раз
  isActive?: boolean;        // Активна ли сейчас
  
  source: 'rabota.md' | '999.md';
}
```

## 🔍 Особенности парсеров

### rabota.md (HTTP)

**Преимущества:**
- ⚡ Быстрый (простой HTTP)
- 💾 Мало памяти
- 🎯 Стабильный HTML

**Особенности:**
- Пагинация: `/profession`, `/profession/page-2`, `/profession/page-3`
- Проверка дубликатов ID для определения конца
- Защита от бесконечного цикла (сайт возвращает последнюю страницу)

**Извлекаемые поля:**
- Базовая информация из карточки (title, company, salary, location)
- Детальная информация со страницы вакансии (education, experience, schedule, workPlace)

### 999.md (Puppeteer)

**Преимущества:**
- ✅ Выполняет JavaScript (Next.js)
- ✅ Видит динамический контент
- ✅ Обходит базовые защиты

**Особенности:**
- Фильтры: `appl=1` (предлагаю работу), `ef=16,50,9394,56,66`, `o_16_1=983`
- Определение реального количества страниц из пагинатора
- Headless браузер Chrome

**Извлекаемые поля:**
- Базовая информация из карточки
- Расширенная детальная информация:
  - Автор (Физ./Юр. лицо)
  - Тип компании и занятости
  - Сезонная работа
  - Требуемые языки
  - Контактная информация
  - Полный адрес

1. Создайте `src/parsers/yourSite.ts`
2. Реализуйте интерфейс `Parser`:

## ❓ FAQ

**Q: Почему 999.md медленнее?**  
A: Использует Puppeteer (headless браузер) для выполнения JavaScript. Это необходимо для Next.js сайтов.

**Q: Как часто нужно запускать парсер?**  
A: Рекомендуется 2-3 раза в день. Вакансии старше 7 дней без обновлений автоматически удаляются.

**Q: Можно ли отключить детальный парсинг?**  
A: Да, в конструкторе парсера:
```typescript
new NineNineNineMdParser({ parseDetails: false })
```

**Q: Где хранятся результаты?**  
A: В JSON файлах в корне проекта: `vacancies_rabota_md.json`, `vacancies_999_md.json`

**Q: Как очистить кэш?**  
A: Удалите папку `cache/` или её содержимое.

## 🐛 Troubleshooting

### HTTP 429 - Too Many Requests
Увеличьте `delay` в конфигурации (например, до 2000-3000 мс).

### Puppeteer не запускается
```bash
npm install puppeteer --force
```

### Пустые результаты на 999.md
1. Проверьте точное название категории на сайте
2. Убедитесь что Puppeteer установлен
3. Запустите `npm run test:puppeteer` для проверки

### Вакансии не обновляются
Проверьте что используете команду `npm run parse`, а не старые команды `npm run start`.
