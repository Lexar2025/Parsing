## 📋 Что делает новый парсер

1. **Запускает headless браузер** (Chrome без интерфейса)
2. **Загружает JavaScript** на страницах 999.md
3. **Ждёт полной загрузки** контента (включая Next.js)
4. **Извлекает данные** из карточек вакансий
5. **Проходит по всем страницам** с пагинацией
6. **Сохраняет результаты** в `vacancies_999md.json`

## 🔧 Особенности нового парсера

### Преимущества Puppeteer:
- ✅ Полная эмуляция браузера
- ✅ Выполняет JavaScript (работает с Next.js)
- ✅ Ждёт загрузки динамического контента
- ✅ Может делать скриншоты для отладки
- ✅ Обходит базовые защиты от ботов

### Параметры в конфигурации:

В `src/parsers/nineNineNineMd.ts` можно настроить:

```typescript
{
  headless: true,        // false для отладки (показывает браузер)
  concurrency: 3,        // количество одновременных страниц
  cacheEnabled: true,    // кэширование результатов
  cacheTTLSeconds: 86400 // время жизни кэша (24 часа)
}
```

## 🐛 Отладка

### Если парсер не находит вакансии:

1. **Запустите с видимым браузером:**
   
   Откройте `src/parsers/nineNineNineMd.ts` и измените:
   ```typescript
   headless: opts?.headless ?? false,  // было: true
   ```

2. **Проверьте селекторы:**
   
   Запустите тест:
   ```bash
   npm run test:puppeteer
   ```
   
   Проверьте скриншот `puppeteer_test_screenshot.png`

3. **Увеличьте таймауты:**
   
   В парсере найдите:
   ```typescript
   await page.waitForSelector('.styles_adlist__3YsgA', { timeout: 10000 });
   ```
   
   Увеличьте timeout до 20000-30000

### Если браузер не запускается:

Попробуйте установить переменную окружения:

**Windows (PowerShell):**
```powershell
$env:PUPPETEER_SKIP_CHROMIUM_DOWNLOAD="false"
npm install puppeteer
```

**Linux/Mac:**
```bash
PUPPETEER_SKIP_CHROMIUM_DOWNLOAD=false npm install puppeteer
```

## ❓ FAQ

**Q: Почему Puppeteer медленнее?**  
A: Puppeteer запускает полноценный браузер для каждой страницы. HTTP парсер только скачивает HTML.

**Q: Можно ли ускорить Puppeteer?**  
A: Да! Можно переиспользовать один браузер для всех страниц, отключить загрузку изображений, использовать кэш.

**Q: Нужен ли Puppeteer для rabota.md?**  
A: Нет! rabota.md работает с обычным HTTP парсингом (axios + JSDOM).

**Q: Что если селекторы изменятся?**  
A: Нужно будет обновить селекторы в коде. Puppeteer позволяет легко проверить актуальную структуру страницы.
