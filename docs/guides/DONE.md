## Запуск

```powershell
# 1. Удалить puppeteer-extra
npm uninstall puppeteer-extra puppeteer-extra-plugin-stealth

# 2. Собрать
npm run build

# 3. Запустить БЕЗ детального парсинга (быстро)
npm run parse makler.md Программисты

# 4. Запустить С детальным парсингом (медленнее, но больше данных)
```

Для включения детального парсинга откройте `src/parse.ts`:

```typescript
case 'makler.md':
  return new MaklerMdParser({
    headless: false,      // false = видно браузер
    parseDetails: true,   // true = парсить детали (ВКЛЮЧИТЬ!)
    cacheEnabled: true,
  });
```

## Управление детальным парсингом

### Отключить (быстрее):
```typescript
parseDetails: false
```
Будут только основные поля со страницы списка.

### Включить (медленнее, но полнее):
```typescript
parseDetails: true
```
Будут все поля + детали с каждой страницы вакансии.

## Кэширование

Детали вакансий кэшируются на 24 часа в `cache/makler-md/`.

Чтобы очистить кэш:
```powershell
Remove-Item -Recurse cache/makler-md/*
```

## Скорость парсинга

- **Без деталей**: ~10 страниц за 1-2 минуты
- **С деталями**: ~10 страниц за 5-10 минут (зависит от количества вакансий)

Детальный парсинг делается параллельно (3 запроса одновременно) для ускорения.
