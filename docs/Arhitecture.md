## 🚀 С чего начать?

### Если вы только начинаете:
1. Прочитайте главный [README.md](../README.md) в корне проекта
2. Следуйте инструкциям из [QUICK_START.md](QUICK_START.md)
3. Изучите диаграммы для понимания архитектуры

### Если настраиваете Puppeteer:
1. Откройте [PUPPETEER_GUIDE.md](PUPPETEER_GUIDE.md)
2. Следуйте шаг за шагом
3. Запустите тест: `npm run test:puppeteer`

### Если хотите понять архитектуру:
1. Откройте `project-architecture.html` в браузере
2. Изучите `rabota-md-flow.html` и `999-md-flow.html`
3. Прочитайте [SUMMARY.md](SUMMARY.md) для полной картины

## 📊 Визуальная навигация

```
Проект парсера вакансий
│
├── 🌐 Источники данных
│   ├── Rabota.md (HTTP)
│   └── 999.md (Puppeteer)
│
├── 🔍 Парсинг
│   ├── HTTP парсер (axios + JSDOM)
│   └── Browser парсер (Puppeteer)
│
├── ⚙️ Обработка
│   ├── VacancyManager (актуальность)
│   ├── Кэширование (24ч TTL)
│   └── Удаление дубликатов
│
└── 💾 Хранение
    ├── JSON файлы (с историей)
    └── Cache папки
```

## 🎯 Быстрые ссылки

### Команды парсинга
```bash
npm run parse rabota.md программист
npm run parse 999.md Грузчик
```

### Команды управления
```bash
npm run manage stats 999_md
npm run manage active 999_md
npm run manage cleanup 999_md
```

### Тестирование
```bash
npm run test:puppeteer
npm test
```
