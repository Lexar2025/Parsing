## Частичное совпадение

Парсер автоматически ищет по частичному совпадению. Например:

```bash
# "Програм" найдет "Программисты"
npm run parse makler.md "Програм"

# "сварщик" найдет "Сварщики"
npm run parse makler.md "сварщик"
```

## Регистронезависимый поиск

Парсер не чувствителен к регистру:

```bash
npm run parse makler.md "ПРОГРАММИСТЫ"
npm run parse makler.md "программисты"
npm run parse makler.md "Программисты"
# Все три команды дадут одинаковый результат
```

## Добавление новых профессий

Чтобы добавить новую профессию:

1. Откройте страницу https://makler.md/transnistria/job/job-offers
2. Откройте инструменты разработчика (F12)
3. Найдите нужный чекбокс с профессией
4. Скопируйте значение атрибута `value` (это ID)
5. Добавьте в словарь `MAKLER_PROFESSIONS` в файле `src/parsers/maklerMd.ts`:

```typescript
export const MAKLER_PROFESSIONS: Record<string, number> = {
  // ... существующие профессии
  'Новая профессия': 1234, // ваш ID
};
```

## Формирование URL вручную

Если хотите сформировать URL вручную:

```
# Базовый URL
https://makler.md/transnistria/job/job-offers?list&list=detail

# С фильтром профессии
https://makler.md/transnistria/job/job-offers?list&list=detail&field_446[]=2869

# С пагинацией
https://makler.md/transnistria/job/job-offers?list&list=detail&field_446[]=2869&page=1

# Несколько профессий
https://makler.md/transnistria/job/job-offers?list&list=detail&field_446[]=2869&field_446[]=2871

# С удалённой работой
https://makler.md/transnistria/job/job-offers?list&list=detail&field_446[]=2869&field_344[]=4619
```
