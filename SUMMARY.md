# 📋 Резюме анализа интеграции hh.ru

## 🎯 Краткий ответ на твой вопрос

**Да, интеграция возможна и рекомендуется.** 

Ты можешь объединить оба проекта в одном месте с минимальными изменениями существующей архитектуры. Ключевое решение - использовать **стратегию поиска**, которая будет автоматически определять, какие источники парсить.

## 🏗️ Архитектурное решение

### Проблема
- Основной проект: парсеры веб-сайтов (HTML + Puppeteer)
- Проект hh.ru: API клиент (REST + axios)
- Нужно объединить с возможностью условной активации hh.ru

### Решение
Создать **единый интерфейс парсера** с разными реализациями:
- `WebParser` - для веб-сайтов (существующие)
- `APIParser` - для API (новый для hh.ru)

Добавить **стратегию поиска**:
- `local` - только локальные сайты
- `international` - только hh.ru
- `hybrid` - все источники

function detectSearchStrategy(query?: string): SearchStrategy {
