# Решение проблемы с парсингом 999.md

## Проблема

999.md использует **Next.js** для динамической загрузки контента. Карточки вакансий загружаются через JavaScript после первичной загрузки страницы, поэтому простой HTTP запрос (axios) не видит данные.

```
✅ HTML сохранен в файл: debug_999_page.html
📋 Проверка селекторов:
1. Контейнер .styles_adlist__3YsgA: ✅ НАЙДЕН
2. Карточки article.AdVacancies_wrapper__oZp_b: 0 шт.  ← ПРОБЛЕМА!
```

## Решение

Нужно использовать **headless browser** (браузер без интерфейса), который выполняет JavaScript.

### Вариант 1: Puppeteer (рекомендуется)

**Установка:**
```bash
npm install puppeteer
npm install --save-dev @types/puppeteer
```

**Преимущества:**
- ✅ Полная эмуляция браузера
- ✅ Выполняет JavaScript
- ✅ Поддержка скриншотов для отладки
- ✅ Хорошо документирован

**Недостатки:**
- ❌ Медленнее обычных HTTP запросов
- ❌ Больше использует память
- ❌ Скачивает Chromium (~170MB)

### Вариант 2: Playwright (альтернатива)

**Установка:**
```bash
npm install playwright
```

**Преимущества:**
- ✅ Поддержка Chrome, Firefox, Safari
- ✅ Более современный API
- ✅ Лучшая производительность

**Недостатки:**
- ❌ Больший размер установки

### Вариант 3: API 999.md (если доступен)

Проверьте, есть ли у 999.md публичное API:
- Откройте DevTools (F12) на сайте
- Перейдите в Network → XHR
- Обновите страницу
- Найдите запросы к API

Если найдете API endpoint - можно использовать его напрямую!
