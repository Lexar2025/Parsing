# Команды для проверки

Выполните следующие команды:

```bash
# Очистка и сборка
npm run clean
npm run build

# Если сборка успешна, запустите тест
npm run parse 999.md Загрузчик
```

Если сборка прошла успешно, вы увидите:
- ✅ Линтер пройден без ошибок
- ✅ TypeScript скомпилирован
- ✅ Создана папка build/

После успешной сборки можете запускать парсер!
