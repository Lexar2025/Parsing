# Инструкция по тестированию парсера 999.md

## Быстрый старт

1. **Соберите проект:**
```bash
npm run build
```

2. **Запустите парсер 999.md:**
```bash
npm run start:999
```

Или используйте универсальный парсер:
```bash
npm run parse 999.md Загрузчик
```

## Что делает парсер

1. Загружает главную страницу раздела "Работа" на 999.md
2. Ищет нужную категорию вакансий (например, "Загрузчик")
3. Добавляет фильтр "Предлагая работу" (appl=1)
4. Парсит страницы с вакансиями (по умолчанию до 10 страниц)
5. Извлекает информацию:
   - Название вакансии
   - График работы
   - Требуемый опыт
   - Образование
   - Ссылка на вакансию
6. Сохраняет результаты в `vacancies_999md.json`

## Примеры команд

```bash
# Парсинг грузчиков
npm run parse 999.md Загрузчик

# Парсинг водителей
npm run parse 999.md Водитель

# Парсинг поваров
npm run parse 999.md "Повар, пекарь, кондитер"

# Парсинг продавцов
npm run parse 999.md "Продавцы, кассиры"
```

**Важно:** Если название категории содержит пробелы или запятые, заключайте его в кавычки!

## Настройка парсинга

Откройте файл `src/config/parsers.ts` и измените параметры для 999.md:

```typescript
'999.md': {
  name: '999.md',
  baseUrl: 'https://999.md',
  defaultCategory: 'Загрузчик',  // ← Измените здесь
  maxPages: 10,                   // ← Количество страниц
  delay: 1500,                    // ← Задержка между запросами (мс)
  concurrency: 3,                 // ← Одновременные запросы
  cacheEnabled: true,             // ← Включить кэш
},
```

## Возможные проблемы

### 1. Категория не найдена
```
Категория "..." не найдена
```
**Решение:** Проверьте точное название категории на сайте 999.md

### 2. Пустые результаты
```
ИТОГО: Найдено 0 вакансий
```
**Решение:** 
- Убедитесь, что категория существует
- Проверьте, есть ли вакансии в этой категории на сайте
- Попробуйте другую категорию

### 3. HTTP ошибки
```
Ошибка HTTP: 429 Too Many Requests
```
**Решение:** Увеличьте `delay` в конфигурации (например, до 2000-3000 мс)
