## Что теперь работает

1. **Поиск по категории** - через канонический справочник
2. **Обычный поиск** - по названию вакансии
3. **Семантический поиск** - с маппингом на источники
4. **Фильтрация по локации** - Молдова/за границей
5. **Парсинг** - синхронный и фоновый
6. **Кэширование** - через Redis
7. **Пагинация** - по номеру страницы

## Следующие шаги

### 1. Выполнить миграцию БД
```bash
npx prisma migrate dev --name add_category_and_dictionary_links_to_vacancy
```

### 2. Запустить сервер
```bash
npm run dev:api
```

### 3. Протестировать
```bash
# Поиск по категории
curl "http://localhost:3000/api/vacancies?keywords=Курьер&searchBy=category"

# Поиск в Молдове
curl "http://localhost:3000/api/vacancies?locationType=moldova&keywords=работа"

# Поиск за границей
curl "http://localhost:3000/api/vacancies?locationType=abroad&keywords=работа"
```
