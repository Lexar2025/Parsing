# Инструкция по запуску проекта

## Шаг 1: Установка зависимостей

Откройте терминал в VS Code (Terminal -> New Terminal) и выполните:

```bash
npm install
```

Это установит все необходимые пакеты:
- axios - для HTTP запросов
- cheerio - для парсинга HTML
- typescript - компилятор TypeScript
- vitest - фреймворк для тестирования
- eslint, prettier - инструменты для качества кода

## Шаг 2: Проверка установки

Запустите тесты чтобы убедиться что все работает:

```bash
npm test
```

## Шаг 3: Первый запуск парсера

```bash
npm run build
npm start
```

Или в двух терминалах одновременно:
- Терминал 1: `npm run build:watch` (автоматическая перекомпиляция)
- Терминал 2: `npm start` (запуск)

## Что будет происходить:

1. TypeScript скомпилируется в папку `build/`
2. Парсер отправит запрос на rabota.md
3. Загрузит HTML страницу с вакансиями
4. Извлечёт информацию о вакансиях
5. Выведет результаты в консоль

## Возможные проблемы и решения:

### Проблема: Ошибки TypeScript при компиляции
**Решение:** Проверьте что все файлы созданы правильно и версия Node.js >= 22.11

### Проблема: Селекторы не находят элементы
**Решение:** Нужно будет:
1. Открыть https://www.rabota.md в браузере
2. Нажать F12 (DevTools)
3. Найти структуру вакансий
4. Обновить селекторы в `src/parsers/rabotaMd.ts`

### Проблема: Ошибка сети или блокировка
**Решение:** Некоторые сайты блокируют автоматические запросы. Возможно потребуется:
- Добавить задержки между запросами
- Изменить User-Agent
- Использовать прокси

## Следующие шаги после первого запуска:

1. Запустите парсер: `npm run build && npm start`
2. Посмотрите что он находит
3. Откройте реальный сайт rabota.md
4. Сравните структуру HTML с селекторами в коде
5. Обновите селекторы если нужно

## Полезные команды:

```bash
# Разработка
npm run build          # Компиляция
npm run build:watch    # Компиляция с отслеживанием изменений
npm start              # Запуск

# Тестирование
npm test               # Запуск тестов
npm run test:watch     # Тесты в watch режиме
npm run test:coverage  # Тесты с покрытием

# Качество кода
npm run lint           # Проверка ESLint
npm run prettier       # Форматирование кода

# Очистка
npm run clean          # Удалить build/ и coverage/
```

## Структура кода:

- `src/main.ts` - точка входа, здесь можно менять параметры поиска
- `src/parsers/rabotaMd.ts` - основной парсер, CSS селекторы здесь
- `src/types/vacancy.ts` - TypeScript типы для вакансий
- `src/utils/helpers.ts` - вспомогательные функции
- `__tests__/` - тесты
- `build/` - скомпилированный JavaScript (создается автоматически)

## Редактирование параметров поиска

Откройте `src/main.ts` и измените:

```typescript
const config: ParserConfig = {
  baseUrl: 'https://www.rabota.md',
  searchQuery: 'программист', // ← Ваш поисковый запрос
  maxPages: 1,
  delay: 1000,
};
```

После изменения файла запустите снова:
```bash
npm run build
npm start
```
