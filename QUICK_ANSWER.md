# 📚 Краткий ответ на твой вопрос

## ❓ Нужно ли вручную обновлять словарик?

**НЕТ, вручную обновлять НЕ НУЖНО** (для обычного парсинга и поиска).

---

## 🎯 Коротко о главном

### Что такое `canonical-professions.ts`?

**Это статический файл** (не БД!), в котором хранятся:
- Канонические названия профессий
- Синонимы для поиска
- Маппинг на источники

**Пример:**
```typescript
{
  canonicalName: "Программист",
  category: "ИТ",
  synonyms: ["разработчик", "кодер"],
  sourceMappings: {
    "rabota.md": ["Программист"],
    "999.md": ["Программист", "Разработчик"],
    // ...
  }
}
```

---

### Что такое `professionDictionary` в БД?

**Это динамическая таблица** в базе данных, которая:
- Обновляется автоматически через воркер
- Хранит названия профессий с сайтов
- Используется для семантического поиска

---

## 🔗 Как они связаны?

### 1. При парсинге вакансии:
```
Вакансия: "Курьер доставки пиццы" на 999.md
  ↓
Адаптер вызывает determineCategory()
  ↓
Ищет в файле canonical-professions.ts
  ↓
Находит: { canonicalName: "Курьер", ... }
  ↓
Сохраняет в БД: { category: "Курьер" }
```

### 2. При поиске по категории:
```
Запрос: /api/vacancies?keywords=Курьер&searchBy=category
  ↓
Ищет в файле каноническое название "Курьер"
  ↓
Ищет в БД: WHERE category = "Курьер"
  ↓
Возвращает вакансии
```

---

## 📊 Сравнение

| | `canonical-professions.ts` (файл) | `professionDictionary` (БД) |
|---|---|---|
| **Тип** | Статический | Динамический |
| **Обновление** | Вручную (когда добавляешь профессии) | Автоматически (через воркер) |
| **Использование** | Определение категории | Семантический поиск |
| **Связь с БД** | Нет | Да |

---

## ✅ Когда НЕ нужно обновлять файл

- ✅ Просто парсишь вакансии → категории определяются автоматически
- ✅ Обновляешь словарики через воркер → обновляется только БД
- ✅ Ищешь вакансии → используется существующий справочник

---

## 🔧 Когда НУЖНО обновить файл

Только когда хочешь:
- Добавить **новую профессию** (которой еще нет)
- Добавить **новые синонимы**
- Добавить **новые маппинги** для источников
- Изменить **категории**

**Пример:**
```typescript
// Добавляешь в файл
{
  canonicalName: "Диджитал-маркетолог",
  category: "Маркетинг",
  synonyms: ["digital маркетолог"],
  sourceMappings: {
    "rabota.md": ["Диджитал маркетолог"],
    // ...
  }
}
```
Потом **перезапускаешь сервер**.

---

## 🚀 Что делать сейчас?

1. **Не трогай** `canonical-professions.ts` (пока)
2. **Парси вакансии** → смотри как определяются категории
3. **Тестируй поиск** → `searchBy=category` и `searchBy=title`
4. **Потом** (когда захочешь расширить) → добавляй профессии из `Словарики.csv`
