# Парсер вакансий - Многофункциональный

Универсальный парсер вакансий с поддержкой нескольких сайтов.

## Поддерживаемые сайты

- **rabota.md** - популярный сайт вакансий в Молдове
- **999.md** - доска объявлений с разделом работы

## Установка

```bash
npm install
```

## Сборка проекта

```bash
npm run build
```

## Использование

### Быстрый старт

#### Парсинг rabota.md
```bash
npm run start
```

#### Парсинг 999.md
```bash
npm run start:999
```

### Универсальный парсер

Для запуска универсального парсера используйте команду:

```bash
npm run parse <сайт> [категория]
```

#### Примеры:

```bash
# Парсинг программистов на rabota.md
npm run parse rabota.md программист

# Парсинг грузчиков на 999.md
npm run parse 999.md Грузчик

# Справка по доступным сайтам
npm run parse --help
```

## Конфигурация

Настройки для каждого сайта находятся в `src/config/parsers.ts`:

```typescript
export const PARSER_CONFIGS: Record<string, SiteConfig> = {
  'rabota.md': {
    name: 'Rabota.md',
    baseUrl: 'https://www.rabota.md',
    defaultCategory: 'программист',
    maxPages: 10,
    delay: 1000,
    concurrency: 3,
    cacheEnabled: true,
  },
  '999.md': {
    name: '999.md',
    baseUrl: 'https://999.md',
    defaultCategory: 'Грузчик',
    maxPages: 10,
    delay: 1500,
    concurrency: 3,
    cacheEnabled: true,
  },
};
```

Вы можете изменить:
- `maxPages` - максимальное количество страниц для парсинга
- `delay` - задержка между запросами (в миллисекундах)
- `concurrency` - количество одновременных запросов
- `cacheEnabled` - включение/выключение кэширования
- `defaultCategory` - категория по умолчанию

## Кэширование

Парсеры используют файловый кэш для детальной информации о вакансиях. Кэш хранится в папке `cache/`:

- `cache/rabota-md/` - кэш для rabota.md
- `cache/999-md/` - кэш для 999.md

Время жизни кэша по умолчанию: 24 часа.

## Результаты парсинга

Результаты сохраняются в JSON-файлах:
- `vacancies.json` - результаты rabota.md
- `vacancies_999md.json` - результаты 999.md
- `vacancies_<сайт>.json` - результаты универсального парсера

Формат данных:

```json
[
  {
    "id": "123456",
    "title": "Название вакансии",
    "company": "Название компании",
    "salary": "1000-2000 MDL",
    "location": "Кишинев",
    "description": "Описание вакансии...",
    "url": "https://...",
    "publishedAt": "2025-01-01T00:00:00.000Z",
    "education": "Высшее",
    "experience": "1-3 года",
    "schedule": "Полный день",
    "workPlace": "Офис",
    "source": "rabota.md"
  }
]
```

## Добавление нового парсера

1. Создайте файл в `src/parsers/yourSite.ts`
2. Реализуйте интерфейс `Parser` из `src/types/vacancy.ts`
3. Добавьте конфигурацию в `src/config/parsers.ts`
4. Добавьте парсер в switch в `src/parse.ts`

## Особенности парсеров

### rabota.md
- Поддержка пагинации (URL: /profession/page)
- Парсинг детальной информации о вакансии
- Кэширование детальных страниц
- Статистика по локациям и зарплатам

### 999.md
- Фильтр "Предлагая работу" (appl=1)
- Пагинация через параметр ?page=N
- Извлечение графика работы, опыта, образования
- Кэширование детальных страниц

## Troubleshooting

### Ошибка "HTTP 429 Too Many Requests"
Увеличьте `delay` в конфигурации сайта.

### Пустые результаты
Проверьте правильность написания категории. Используйте точное название из списка на сайте.

### Ошибки при парсинге
Проверьте структуру HTML на сайте - возможно, изменилась верстка.
